# OSPF Routing Project

## Overview

This project demonstrates dynamic routing using **Open Shortest Path First (OSPF)** in Cisco Packet Tracer. OSPF enables routers to exchange routing information and calculate paths to remote networks.

## Objectives

- Understand the purpose of OSPF.
- Configure OSPF on Cisco routers.
- Enable the exchange of routing information.
- Inspect OSPF neighbor relationships and routing-table entries.
- Test connectivity between network segments.

## Project Files

- `OSPF-Routing.pkt` — Cisco Packet Tracer project file.
- `OSPF-Topology.png` — Network topology image.

## Verification Commands

```text
show ip ospf neighbor
show ip route
show ip protocols
```

These commands can be used in the router CLI to inspect OSPF neighbors, learned routes, and the active routing protocol.

## Expected Learning Outcome

Understand how OSPF forms neighbor relationships and shares routing information so routers can reach networks beyond their directly connected links.
